# Jhonalie Jotajero — Personal Portfolio

A responsive, user-friendly personal portfolio and CIT 240 Open Source Programming capstone showcase built with semantic HTML5, Tailwind CSS, React, and TypeScript.

## Features

- **Semantic HTML5 Structure**: Organized using `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` landmarks with keyboard skip-navigation support.
- **Responsive Design**: Mobile-first layout scaling smoothly from smartphones (`360px`) to desktop (`1440px`) viewports, including a mobile navigation drawer.
- **Interactive Controls**: Light/Dark theme switch, skill category filtering, project category filtering, interactive live project demos, printable resume summary modal, and an accessible contact form.
- **Zero-Broken-Media Safeguards**: Local profile portrait asset and crisp inline UI previews for featured projects.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
